ESP32-C6 Zigbee coordinator for Home Assistant

C6 Zigbee Stick turns an ordinary ESP32-C6 board into a Zigbee coordinator. Flash the firmware from this page, plug the board into Home Assistant, and the integration finds it and sets up Zigbee2MQTT. No terminal, no YAML.

1. Flash the ESP32-C6 from your browser

Connect the board to your computer with a data USB cable (to the USB connector, not UART) and press the button. Works in Chrome and Edge on a computer.

Firmware: esp-coordinator 1.5.80 (Espressif ZBOSS stack, NCP over USB), unmodified. The board's flash is fully erased.

2. Add the integration through HACS

Once per Home Assistant: open the repository in HACS with the button below (or add https://github.com/f1devbin/c6-zigbee-stick as a custom repository of type “Integration”), install “C6 Zigbee Stick” and restart Home Assistant.

Open in HACS

3. Plug the stick into Home Assistant

A “Discovered: C6 Zigbee Stick” card appears in Settings → Devices & services. Press “Add”: the integration installs and starts Zigbee2MQTT (and the Mosquitto broker if there is no MQTT yet), points it at the stick and restarts it when the stick is plugged back in. Then pair Zigbee devices in Zigbee2MQTT with “Permit join”.

Supported boards

Any ESP32-C6 board whose USB connector is wired to the chip's own USB: ESP32-C6-DevKitC-1, ESP32-C6-DevKitM-1, Seeed Studio XIAO ESP32C6, WeAct ESP32-C6 and similar. On boards with two connectors use the one labelled USB, not UART or COM.

FAQ

Can an ESP32-C6 be a Zigbee coordinator?

Yes. The ESP32-C6 has an IEEE 802.15.4 radio. With Espressif's ZBOSS stack in network co-processor mode it works as a coordinator, and Zigbee2MQTT talks to it with its zboss adapter.

Does it work with ZHA?

Not yet: Home Assistant's built-in ZHA has no ZBOSS support, so the integration uses Zigbee2MQTT.

Why does Home Assistant need an integration for it?

Retail sticks are recognised by the name in their USB descriptor. Every ESP32-C6 reports the same fixed descriptor (303a:1001, “USB JTAG/serial debug unit”), so the integration asks the board over the ZBOSS protocol whether it really is a coordinator before offering to set it up.

What are the limitations?

Zigbee2MQTT's zboss adapter is marked experimental: changing the channel means re-pairing devices, and network backups, install codes and touchlink are not supported yet.
